# Restaurant Platform — dev preview (Шаг 0 плана)

Это самый первый, минимальный срез плана: одно гостевое меню (Pomodoro),
без базы данных, без заказа, без оплаты — просто чтобы проверить, что
стек работает и есть на что посмотреть на реальном телефоне через QR-код.

Меню сейчас хранится прямо в коде (`src/lib/data/venues.ts`) —
это **заглушка**, замени названия/описания/цены на настоящее меню
Pomodoro перед тем как показывать это гостям.

## Как запустить у себя

Открой терминал в этой папке и выполни:

```bash
npm install
npm run dev
```

Затем открой в браузере: http://localhost:3000

Гостевое меню (все 3 языка):
- http://localhost:3000/ka/menu/pomodoro — ქართული
- http://localhost:3000/ru/menu/pomodoro — Русский
- http://localhost:3000/en/menu/pomodoro — English

## Как посмотреть с телефона (по QR-коду)

1. Узнай локальный IP своего компьютера в той же Wi-Fi сети:
   - Windows: `ipconfig` → строка "IPv4 Address" (например 192.168.1.23)
2. Запусти `npm run dev` (сервер слушает на всех интерфейсах по умолчанию)
3. На телефоне (в той же сети) открой `http://<твой-IP>:3000/ru/menu/pomodoro`
4. Сделай QR-код на эту ссылку любым бесплатным генератором QR
   (например qr-code-generator.com) и отсканируй его телефоном

## Админ-панель и база данных (Supabase)

Начали подключать настоящую базу данных (Postgres на Supabase) и
админ-панель `/admin`, чтобы менять фото/цены/тексты без правки кода.

**Что нужно сделать один раз, по порядку:**

1. Останови сервер (`Ctrl+C` в окне с `npm run dev`), затем:
   ```bash
   npm install
   ```
   (подтянет новые пакеты: prisma, @prisma/client, supabase)

2. Зайди на [supabase.com](https://supabase.com), создай бесплатный
   аккаунт и новый проект (любое имя, любой регион поближе — например
   Frankfurt). Придумай и сохрани себе пароль от базы данных — он
   понадобится один раз для строки подключения.

3. В проекте зайди в **Project Settings → Database → Connection string**,
   выбери вкладку **URI**, скопируй строку — в ней вместо `[YOUR-PASSWORD]`
   подставь свой пароль. Также зайди в **Project Settings → API** и
   скопируй **Project URL** и **anon public** ключ.

4. Скопируй файл `.env.example` в `.env` и вставь туда эти три значения.

5. Пришли мне: строку подключения (DATABASE_URL), Project URL и anon key —
   я сразу продолжу настройку (миграции, перенос текущего меню в базу,
   создание учётной записи для входа в админку).

После этого админка будет доступна на `/admin/login` — вход по
email/паролю сотрудника (создаётся в Supabase Dashboard →
Authentication → Users).

## Структура проекта

```
src/app/[locale]/menu/[venueSlug]/page.tsx  — гостевая страница меню
src/app/admin/**                             — админ-панель (вход + редактор меню)
src/app/api/admin/**                         — API для сохранения правок
src/lib/data/venues.ts                       — старые данные меню (заглушка, используется пока БД не подключена)
src/lib/db/venues.ts                         — чтение меню из базы данных (Prisma)
src/lib/admin/auth.ts                        — проверка прав доступа в админке
src/lib/supabase/*                           — клиенты Supabase Auth
src/lib/i18n.ts                              — переводы интерфейса (ka/ru/en)
prisma/schema.prisma                         — схема базы данных
prisma/seed.ts                               — перенос venues.ts в базу данных
```
